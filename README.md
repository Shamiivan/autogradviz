# Autogradviz

Autogradviz is a small tool that shows how a neural network learns the Iris dataset. You press train and watch the network run, step by step. The SVG canvas draws every neuron and weight so you can see activations, gradients, and how the weights react to each sample.

This project started as a teaching aid for automatic differentiation. It is not meant to be a framework or a glossy product. It is a clear window into the guts of backprop.
